## 实际修复与小范围重构

1. 启动参数校验独立成 `parse_arguments()`；`--duration` 必须是有限正数，在读取配置、建目录或创建进程前拒绝 NaN、正负无穷、零和负数。
2. `--check --resource-check` 现在执行显式请求的资源检查；普通 `--check` 仍不探测 CPU/内存，正常启动仍优先拒绝缺失运行依赖。未改变导航算法、安全阈值或进程清理策略。
3. 增加六项 CLI 回归测试；检查分支测试禁止文件打开与进程创建，避免测试误启动系统。
4. `.gitignore` 排除 `.dsh-subagents/`，保留本地会话文件；修正场景文档的实际配置/源码路径、失效链接和 Vikit COPYING 的陈旧说明。
