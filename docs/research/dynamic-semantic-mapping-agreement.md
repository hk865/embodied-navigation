## 从原话可以确认的研究目标

以下为原话的整理，**不是逐字引文，也不是已完成清单**：

- 维护静态与动态分层的地图，结合几何或运动证据和语义先验，减少动态物体对静态地图的污染。
- 保留包含历史的运动趋势、语义信息及对象 ID；对象被标记后，研究通过运动和结构延续身份，减少重复语义识别。
- 在关键帧或事件发生时调用语义模型，之后利用已有标记与跟踪，不要求每一帧重新识别。
- 将点云、深度、语义和对象关系编译成可查询的结构化 context，为 Agent 记忆、主动探索建图及 VLN 提供输入。
- 用后续 benchmark 和实际导航实验验证效果。

本轮另有明确的执行目标：在当前具身导航工程中推进办公室楼梯通行与多层建图，随后加入行人并验证动态导航；巡航目标约 1 m/s，楼梯不自动限速，记录实际速度与控制参数。这是本轮工作目标摘要，不能用早期低速楼梯记录替代其验证。

## 未定参数与助手建议

历史记录中没有找到已经决定的 **每 N 帧或每 N 秒调用频率、具体阈值、最终模型、对象关联算法或环境表示 schema**。不能把某次实验默认值追记为历史约定。

| 项目 | 原话已经明确的方向 | 尚待决定或验证 |
| --- | --- | --- |
| 语义调用 | 关键帧、进入另一处可观察区域或事件触发；不必逐帧识别 | 触发信号、冷却时间、预算、队列和失败处理 |
| 动静判断 | 分割先验，加上特征差异或运动证据 | 运动补偿、阈值、置信度、静止行人的处理 |
| 对象 ID | 保留身份，并研究运动或结构跟踪 | 关联算法、遮挡/跨视角重识别、拆分合并与过期规则 |
| 历史地图 | 静态、动态、语义及历史运动趋势 | 历史保留长度、关键帧锚点、回环后修正与多楼层表达 |
| 环境编译 | 结构化文本、代码或自定规范，支持关系表达 | schema、查询接口、空间关系、可见性与不确定性表达 |
| 评测 | VLN、PCT planner 与 benchmark 方向 | 任务、数据集、对照、指标及成功判据 |

视野重叠率、距离或时间触发等是助手提出的**候选设计**，需要实测，不是用户已经确定的阈值。语义识别低频调用，也不意味着可以只在低频时排除动态点：两次识别之间如何持续跟踪、如何处理未知点，是实现仍须回答的问题。

当前工程接入时的助手建议是：保留完整观测供导航发现行人，为 SLAM 与静态持久地图另分配经过动静判断的输入；记录对象、观测时间、位姿来源及不确定性。仅向地图追加语义 JSON，不能证明静态地图已经免受动态污染。此段为实现建议，不是历史用户原话。
