# 四台 120° 相机真实采集与五台对照

四台 **120° 水平视场、0/90/180/270° 朝向**已完成 20 仿真秒的真实 Isaac RTX 采集及原生视觉旁路回放。四路均有有效视觉修正；相同裁边下的点覆盖优于五台 82.37° 对照，但实际跟踪点明显更少。本轮支持将四台作为 DSH 环视候选，尚不能判定运动定位精度或正式融合收益。

默认 24/42 光学比例、原配置文件和既有五/六台数据均保留。广视场由显式实验参数开启；实验中的前相机也改为 120°，前端仍只有这一台 RGB 输入。没有额外保留第五台机器人相机。所有实验均另有同一个不变的 overview 相机，资源数字包含其开销。

## 原生投影模型与标定

采用零畸变理想 **pinhole**，512×512，主点 (256,256)，横/纵 aperture 均为 42。120° 所需的 authored focalLength 为 12.12435565298；实际原生 CameraParams 报告 **12.12435531616**，float 精度差在校验容差内。换算 fx=fy≈147.801669px，水平和垂直视场均约 120°。它没有被当作鱼眼模型，也没有沿用旧 fx≈292.571429。

- 每个接受帧都检查 pinhole、分辨率、焦距、aperture、零 offset 和米制单位。80 对归档的 RGB/轴向深度额外保存了对应原生参数，离线再次全部通过校验。
- 前端启动前提供独立的实验标定 JSON；启动服务实际读回 `cam_model=Pinhole`、512×512 和 fx/fy≈147.801669，与 capture 安装收据一致。
- 新增 launcher 预检：显式 HFOV 与 `CAPTURE_CALIBRATION` 不一致时，在创建运行目录/启动 GPU 前拒绝。120° 配旧 24/42 内参的负例已验证会拒绝。
- 内外参来源是作者设置的固定安装位置及原生内参核验；投影使用测得 LIO 状态，不用 renderer 世界位姿修正外参。

当前 SDK 的 `Gf.Camera` 已独立核验上述 Perspective 参数返回 120.0°。USD 焦距与 aperture 使用同一尺度的比值；不能仅根据旧变量名 `FOCAL_MM` 把它当作实体广角镜头标定。[OpenUSD Camera 属性与单位](https://openusd.org/dev/api/class_usd_geom_camera.html)

## 裁边后范围与实际视觉更新

与既有四层 pyramid、patch_size=8 一致，原生边界保护为每边 80px。特征中心的名义选择区域为 [80,432)×[80,432)，面积占原图 47.27%；四台广视场的中心选择水平范围约 **99.95°**，相邻远场理想重叠约 **9.95°**。五台窄视场的相应范围约 62.06°，相隔 72° 时有约 9.94° 的远场缝隙。

这些角度是针孔和裁边的几何范围，不是连续实际跟踪或无遮挡保证。半径约 0.3m 的安装偏移、场景遮挡、纹理、法向和 patch 筛选都会继续限制约束。DSH 可查看整个 120° 原图，不受跟踪中心 80px 裁边限制。

固定曝光和每帧独立曝光两模式都实际运行冻结 native VIO。每路处理 15 个约 1Hz 归档时刻，第一帧建立私有 patch 缓存，随后 **14/14** 均有 retained numerical visual update。不是已完成四路 10Hz 在线视觉估计。

四台累计为固定曝光 2,136、独立曝光 2,142；五台为 4,807、4,808，独立曝光累计少约 **55.45%**。四台最后时刻实际选中 patch 中心为 63/37/26/50 个；对应五台为 124/95/44/35/99。实际点数减少，不应由“视场更广”推断约束更多。相同 512px 下，中心像素/度由约 5.11 降至 2.58；这是可能影响细节/跟踪的因素，并非本轮已经隔离证明的唯一原因。

另在不修改 native 核心的回放诊断中读取实际选中的 patch 中心：四台最后时刻全部在 [80,432) 内，各路水平中心约跨越 81..431px，垂直总体只在约 142..350px。按统一 8×8 中心窗口诊断格统计，各路有点的格数为 31/19/16/26（每路 64 格），五台为 58/48/31/25/48。它是一个时刻的特征分布描述，不是场景面积覆盖率。`four_native_tracking.png` 和 `five_native_tracking.png` 标出了实际选点与裁边；开启/关闭这些只读记录的四/五台位姿增量及物理协方差差值均为 0。

灰度 MSE 单位是强度平方，不是米制定位误差；tracked 实例和 patch 像素也不是相互独立的观测。不同朝向、内参和实际物理代之间不能直接按 MSE 排名定位精度。

公共物理协方差来自本次真实 native 19D 状态的 18D 边缘分布，原前相机曝光被边缘化，每路独立曝光使用显式 N(1,0.1) nuisance 模型。所有有效后验物理协方差均可 Cholesky 分解，但统计一致性未校准。没有用 ROS unavailable/占位协方差。

两个模式都验证：共享 native 状态/点/树在回放前后不变；四路中的前相机与独立单前相机 control 的 pose increment 和物理协方差差值为 0。CI 仅输出离线诊断，`confidence_calibrated=false`、`estimator_feedback_enabled=false`，没有发布或回写正式定位。
