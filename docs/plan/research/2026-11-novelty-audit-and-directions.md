## 1. 先给最诚实的现状定性（Area Chair 视角）

### 1.1 按今天（2026-11-24）仓库现状直接投稿的真实判决
- **工程评价**：极扎实。单人 + 多 Agent 协同拉通了 7 层物理闭环（`src/` 2.7 万行、`tests/` 2.2 万行、18 个 C++ patch、807 单测 + 60 回归全绿、1h 51m / 343.72 m 两层带噪 IMU 闭环、R3LIVE 室外 4 序列与 M3DGR 动态序列实测）。
- **学术投稿判决（`gpt-6.2-astra` 独立审计结论）**：
  - 按现状直接投 `ICRA / IROS / RA-L` 完整方法稿：**弱拒**（主观单次录用估计 **10%–25%**）；
  - 直接投 `RSS / CoRL / CVPR` 综合系统稿：**拒稿**（主观单次录用估计 **< 10%**）。
- **核心原因**：大框架层面已被 2025–2026 顶会与预印本全面占坑；而我们现有最大的定量降幅主要来自修复自家旧版的调度缺陷，尚未证明外部强基线存在同类问题，也尚未补齐跨场景、跨后端的闭环任务净收益。

### 1.2 投稿/汇报中必须严格守住的 4 条数据边界（防审稿人一击毙命）
1. **不要把 `-68.7%` 写成打败 `FAST-LIVO2` 前端**：在 `343.72 m` 两层同包重算上，全程 Umeyama 对齐在线 ATE 是**前端 `2.40 cm`、旧双目标后端 `8.56 cm`、统一修复后端 `2.68 cm`**（终图 `2.40 / 2.49 / 2.02 cm`；共享初始 SE(3) 在线 `9.69 / 11.52 / 8.80 cm`、终图 `6.62 cm`）。正确表述是“消除混合后端引入的在线严重退化，并在初始坐标系及终图上取得稳定改善”。
2. **明确区分“累计震荡总路程”与“单步振幅”**：`max_cum_jitter_m` 从 `13.67 m → 1.52 m`（均值 `4.97 m → 0.34 m`）是单个历史关键帧在 1h 51m / ~100 轮优化快照间反复拉扯的**累计总路程**，不是机器人瞬间瞬移 13 米；单次最大跳变 `max_single_step_shift_m` 为 `43.9 cm → 14.5 cm`，相对首次位置最大偏移 `max_shift_m` 为 `47.5 cm → 14.5 cm`，`p95_iqr_m` 为 `11.9 cm → 3.5 cm`。且历史图抖动**不能自动等同于控制器收到的真实扰动**。
3. **R3LIVE 室外最有价值的是“坡道失效反例”**：固定室内平层先验在 7–8 m 坡道炸到 `89–350 cm`；手动切室外配置后 `hku_campus_seq_02` 闭合 `28.23 → 5.29 cm`、`hku_park_01` Z 漂移 `76.48 → 0.12 cm`（物理放回偏移 `56.8 cm`），但 `hku_park_00` 3D 闭合从前端 `2.19 cm` 略退化到后端 `3.25 cm`——目前尚不能宣称“自动地形适应”或“室外全程厘米级碾压”。
4. **M3DGR 动态序列要同时报在线与终图**：`Dynamic01`（室内 VRPN）前端/在线/终图 ATE 为 `2.46 / 1.45 / 0.97 m`，`Dynamic03`（室外 RTK）为 `4.61 / 4.20 / 1.79 m`。行动当下在线仍高达 `1.45–4.20 m`，归因到动态点必须做同前端同序列的过滤开关消融。

## 3. 五大候选研究 / 子模块优化方向深度评估

结合 Astra 评审与用户最新提出的“单子模块极致优化”思路，当前保留并记录的 5 个方向如下：

---

### 方向 D（Astra 首推 ★★★★★）：回环修订后的「机体相对路径与净空风险交付门控」（L3 ↔ L5）
- **核心问题**：一次真实 SLAM 回环改图后，机器人正在执行的路径在**机器人自身坐标系**里究竟变了多少？什么情况下可以无视全局跳变继续走，什么情况下必须在窄门/楼梯入口立刻局部重规划或停稳？
- **数学核心**：
  设修订版本 $k$ 下机器人位姿为 $T_b^{(k)}$、活跃路径/障碍锚点为 $T_g^{(k)}$，控制器真正关心的相对目标是
  $$Y^{(k)} = \left(T_b^{(k)}\right)^{-1} T_g^{(k)}, \qquad \delta_g = \log\!\left[\left(Y^{(k-1)}\right)^{-1} Y^{(k)}\right].$$
  对两者同时左乘任意世界刚体变换 $G$ 时，$Y^{(k)}$ **严格不变**——因此**“历史图累计修订 13.67 m 或整图平移 30 cm 可以零风险，而门框/楼梯入口仅 4 cm 的相对横向偏移在 3 cm 净空下就会撞墙/跌倒”**。进一步结合短时域机身扫掠体最小净空变化与联合协方差，构成跨后端的通用交付门控。
- **最近竞品与差异**：2026-11-19 的 `Sun et al.`（[arXiv:2611.25788](https://arxiv.org/abs/2611.25788)）证明了楼梯/台沿入口厘米级误差影响通过性，但未从真实 SLAM 回环修订中计算相对风险并决策继续/重规划/停稳。
- **最致命审稿质疑与反制**：*“ROS REP-105 连续 `odom` + 周期局部重规划早就解决了”* → 必须用**共同刚体变换阴性对照** + **局部相对扰动阳性对照**正面硬刚连续 `odom` 周期重规划、全重规划、RTAB-Map 图锚定路径。
- **最大优势（极速止损）**：**2 周筛查即见生死**（若真实回环几乎不伤标准 `odom` 控制器，立刻停掉 D 切回 A/E，绝不白耗数月）；信号成立则 **6–10 周**可冲 **`RA-L / ICRA`**，跨后端跨机器人后可冲 **`RSS`**。

---

### 方向 E（用户提出的高壁垒底层方向 ★★★★☆）：四足 RL 本体先验驱动的「动态点云残差选优与历史轨迹建模」（L6 → L2）
- **核心问题**：动态人群/车辆遮挡大半视场时，纯外感动态滤除陷入“定位不准 ↔ 辨不清动态点”的鸡生蛋死锁（也是 M3DGR `Dynamic03` 在线漂到 `4.20 m` 的核心诱因）。
- **数学核心**：
  利用机器狗**永远不被行人遮挡的本体信号**（电机编码器 + 足端接触 + IMU + `MoE-CTS` RL 策略隐状态），预测帧间本体运动先验 $\hat{\mathbf{T}}_{\text{prop}}$ 及其**异方差协方差** $\Sigma_{\text{prop}}$（平地极紧、踩滑/上下楼梯自动放松），构建带本体锚的联合鲁棒子集选择（GNC-IRLS）问题：
  $$\min_{\Delta \mathbf{T}_t \in SE(3),\; \mathbf{w} \in [0,1]^N} \left\|\log\!\left(\hat{\mathbf{T}}_{\text{prop}}^{-1}\Delta \mathbf{T}_t\right)\right\|_{\Sigma_{\text{prop}}^{-1}}^2 + \sum_{i=1}^{N}\left[w_i\, r_i^2(\Delta \mathbf{T}_t) + \Psi(w_i)\right] + \gamma \sum_{(i,j)\in\mathcal{E}}|w_i - w_j|.$$
  同时把被剔除的动态点簇（$w_i \approx 0$）送入历史帧轨迹跟踪器，识别“曾移动、此刻静止”的人/车并供局部规划避障，彻底杜绝静图鬼影墙。
- **最近竞品与差异**：`PrO` 做了 RL 隐状态本体里程计但只用于盲走目标；`ViQu-SLAM` / `Panoptic-SLAM` 仅用常规正向运动学 + 2D 语义掩码；`SuperMap` 侧重上层 4D 语义图清理；`TIC-VLA` 走端到端避人不做动态 SLAM。**把 RL 控制隐状态及异方差协方差引入 LiDAR+RGB 动态点残差选优，在 2026 年底依然稀缺且纯大模型编排团队根本做不出来。**
- **最致命审稿质疑与反制**：① *“普通 FK 腿部里程计 + `DUFOMap` 不就够了吗？”* → 必须设置严格消融（无过滤 vs `DUFOMap` vs 2D 语义掩码 vs FK 腿部先验 vs `MoE-CTS` 隐状态+协方差先验），重点测**滑移/楼梯/人群高遮挡（50%–70% FOV）**下的优势；② 需解决仿真实测与真实公开数据（M3DGR 无腿部电机信号，仅可验证外感几何/语义侧，需额外找带关节编码器的四足公开动态数据集或实机验证）。
- **定位与工期**：**8–12 周**，非常适合 **`RA-L / ICRA / IROS / CoRL`**，同时能直接把仓库里的 `ref/dynanav-dynamic-pedestrian` 支线盘活。

---

### 方向 A（稳健备胎 ★★★★☆）：重力 $g$ 与支撑面法向 $n_k$ 双潜变量解耦的「地形自适应统一在线 BA」（L3）
- **核心问题**：如何在单一冻结配置下同时兼顾室内平层精准 Z 约束与室外 7–8 m 大坡道无爆炸，同时维持统一目标的低在线往返抖动？
- **数学核心**：
  将重力方向 $g$（由 IMU 与静止段约束）与局部支撑面法向 $n_k$（由邻域点云约束）显式拆分为两个潜变量，对“平地 / 连续坡面 / 支撑证据不足”建立边际似然或可校准模型切换，并给出**单斜面 + 未知 IMU 偏置下的退化可观性分析**；同时用**多余往返修订量**
  $$E_i = \sum_{k>i}\|p_i^{(k)} - p_i^{(k-1)}\| - \|p_i^{(\text{last})} - p_i^{(i)}\|$$
  严格区分“一次必要大修正”与“有害来回摆动”。
- **定位与工期**：**6–10 周**，稳发 **`RA-L / ICRA / IROS`**（也是 D 第 2 周止损失败后的最顺滑切换路线）；主表必须纳入 `Voxel-SLAM`、`HBA`、`MAD-BA` 与地面动态加权基线。

---

### 方向 B / L4 记忆子模块优化（工程价值 ★★★★★，论文风险较高 ★★★☆☆）：原型实例化 Mesh + 四层金字塔空间记忆（L4）
- **工程视角（强烈推荐做）**：
  直击现有 `MapStore`（`256 MB`）+ `agent_evidence/`（`2.6 GB`）体量臃肿与纯 LiDAR Surface Nets 几何粗糙的痛点：
  1. **结构/物体分层**：墙/地/楼梯用 LiDAR 平面或 2DGS+CPU TSDF；前景物体用 `Grounded-SAM2` 前景深度剥离分割 → 查 DINOv2+几何原型库（命中同款 `< 50 ms` 直接实例化复用，仅新款调用 `Hunyuan3D Shape / TRELLIS` 冷启动生成）→ 重力锁定 4-DoF+3 尺度 + LiDAR 表面/Free-Space 配准 → 锚定关键帧 $O(1)$ 随回环形变。
  2. **四层检索金字塔**：`L0 全局拓扑语义 (<1 KB 常驻) → L1 区域/时间摘要向量召回 → L2 物体原型资产集合 → L3 按需关键帧高清 RGB`，同时实现 **25×–100× 存储压缩、5×–10× 重建提速、更高检索召回率与更低 VLM Token 消耗**。
- **论文视角（严格按 Astra 预警收窄）**：
  - 因为 `Real2USD v2`、`Chen 2609`、`OV-PEAR`、`ShapeR` 已经占领了前半段，**绝不能只写“资产检索 + 生成 + Free-Space 验证 + USD”**；
  - 唯一可打顶会（`CVPR / RSS`）的窄缝是：**「SLAM 回环非刚性位姿修订后，增量撤销并重算已失效的旧自由空间射线证据」**（给出相对全量重放的误差与耗时界），并用原生 USD 留出真值（严格隔离资产 ID 防泄漏）与下游碰撞率验证。
  - **止损建议**：先花 1 周用 10–20 个代表物体测“单锚点刚体移动 vs 每次全量重放 vs 增量撤销”的差距；若差距小于测量噪声，则把它纯粹当**工程王牌记忆子模块**落地，不硬凑视觉顶会论文。

---

### 方向 C（配套协议 ★★★★★，独立论文 ★★★☆☆）：可重复分叉的「回环决策事件配对评测协议」
- **核心思想**：把评测单元从“单栋楼长轨”改为“**回环前固定物理状态 → 分叉运行不同修订交付/定位策略的独立物理滚动**”，用配对损失差 $\Delta L = L_{\text{策略1}} - L_{\text{策略2}}$ 精准归因失败属于估计器、交付接口、局部规划还是底层执行。
- **定位**：优先作为 **D / A / E 的硬核实验协议**（4–6 周）；只有在扩展到多建筑、多策略、可公开复现资产后才考虑独立投 Benchmark 论文（12–20 周）。

## 5. 给下一次对话的直接决策清单（3 条快速启动入口）

在新会话里拍板后，可直接按对应入口启动第 1 周行动（均带明确止损门）：

1. **若优先冲一篇极难撞车、最快见结果的顶会论文 → 启动「D 的 2 周止损筛查」**：
   - 第 1 周：对齐 `D-Indoor-2F`（101 次回环）的 5 个时间戳（传感 → 优化完成 → `map→odom` 发布 → 规划消费 → `cmd_vel`），输出完整事件表，量化全局跳变 vs 机体系相对路径/净空变化 $Y^{(k)}$。
   - 第 2 周：在走廊/窄门/楼梯入口/平台分叉闭环滚动，正面对比标准连续 `odom` + 周期重规划；无显著收益则立刻切向 **A** 或 **E**。
2. **若优先攻克四足动态环境真痛点 + 拿硬核交叉论文 → 启动「E 的 2 周原型验证」**：
   - 第 1 周：从 `MoE-CTS` 提取策略隐状态 + 关节/IMU 速度增量，先在静态两层 + `ref/dynanav-dynamic-pedestrian` 上评估本体先验与异方差协方差精度。
   - 第 2 周：实现本体锚定残差选优滤除，在密集动态行人遮挡下对比无过滤 / `DUFOMap` / 2D 语义掩码的定位与鬼影率。
3. **若优先把具身空间记忆与 3D 资产重建做扎实好用 → 启动「B/L4 的最小闭环原型」**：
   - 第 1 周：在 `D-Indoor-2F` 的 `2,460 KF` 上抽 10–20 个典型家具，离线串行跑通 `Grounded-SAM2` 前景深度剥离 → DINOv2 原型检索 → `Hunyuan3D-2 Shape` 冷启动 → LiDAR 表面/Free-Space 4-DoF+3 尺度配准，并同步测存储压缩比、检索召回率与回环前后自由空间射线矛盾度。

## 6. 2026-11-25 补充核查与三轴计划收敛

围绕 2026-11-25 对 VLN 基准、免训练 Agent（`SuperNav / ASENA / HarnessVLN / AgenticNav / EvolveNav / EvoNav`）与 `GPT-6.2-Astra` 二轮弱点审计，补充 4 条关键收敛结论（详见 [2026-11-vln-perception-memory-strategy-synthesis.md](2026-11-vln-perception-memory-strategy-synthesis.md)）：

1. **整体演进明确收敛为「感知（动态 + 语义）+ 记忆（表达 / 场景描述 / 子地图检索 / 存储模态 / 失效治理）+ 失败驱动的控制策略」**：底层 L3 几何 SLAM 与 L5/L6 运动执行保持冻结底座，不再做无边界横向发散。
2. **新增两条硬核证据与接口排雷**：
   - **记忆税与过拟合证据**：`MemoryAgentBench` 单跳实验在检索均命中最新事实的情况下，证据预算从 `64 → 512` token 反而令准确率从 `45% → 32%`；`VSI-Bench` 证明位置有估计误差时，提高结构地图分辨率（`10×10 → 20×20`）反而降分（`56% → 54%`）；新增 2026-11 近邻竞品 `EvoNav`（[arXiv:2611.22321](https://arxiv.org/abs/2611.22321)）已覆盖通用“经验蒸馏进环境知识”，故记忆创新必须收窄至**地图版本冲突 / 过时经验撤销 / 带置信度分布门控**。
   - **方向 E 接口与文献核查**：当前 `MoE-CTS` 包装公开只返回 12 维动作，策略隐状态导出需先单独核实；`PrO` 简称在文献中未能唯一对应原论文，惯性/四足本体不确定性侧应直接对标已核实的 **`AirIMU / AirIO (2025)`、`AI-IO` 与 `Legolas (CoRL 2024)`**。
3. **两条 2 周止损探针优先排期**：
   - **记忆线探针**：在 `D-Indoor-2F` 固定路口、观测与地图版本，只替换 1 条旧经验测试翻错率，并正面硬刚朴素强基线“同楼层最新可见证据 + 按需看原图”；
   - **动态感知线探针**：先不重训 RL，直接向扫描匹配器注入准确机体运动，在人群遮挡下测静态/动态点分割与在线 ATE 上界增益，信号显著后再投入 RoboGauge 极端地形（30 cm 台阶、悬崖、凹坑、烂泥阻力）本体协方差采样与交替迭代动态 SLAM。
