## 1. 统一评测口径与独立审核修复摘要

经独立审核器（Codex `gpt-6.2-astra`，非 fast 模式，高推理强度）对代码、23 份仓内配置、文档及数据盘归档进行全量审计，本轮交付已修复全部 4 项 P0 阻断项及关键 P1/P2 项，并在干净提交上重跑全部 27 组对照：

1. **统一机身参考原点（P0-1）**：前端快照写入 `go2_imu` 世界位姿，真值流记录 `go2_base` 世界位姿。评测器新增 `--imu-in-base-xyz` / `--preflight-json`，按冻结安装外参 `imu_translation_in_base = [0.0201530643, 0.0, -0.0051089553] m` 在对齐前对全层轨迹与 TUM 导出统一右乘 $T_{\text{imu,base}}$，消除转向杆臂误差。
2. **位姿图精确 SE(3) 右雅可比逆（P0-2）**：`pose_graph.py` 补全闭式 $\mathcal{J}_r^{-1}(e)$（含小角度稳定泰勒展开），使 $J_b=\mathcal{J}_r^{-1}(e),\ J_a=-\mathcal{J}_r^{-1}(e)\,\mathrm{Ad}(T_b^{-1}T_a)$，消除大残差下真实梯度未归零即收敛的缺陷。
3. **Layer 2 同前缀回环收益与 Layer 3 入图起点追踪（P0-3 / P1-13）**：单条回环收益改为对同一组历史节点 `0..k-1` 在优化前/后、同一对齐下求差；Layer 3 从各关键帧入图初始位姿开始累计修订，并分列 `p95_IQR`（误差模长 IQR P95）、`max_shift`（相对入图最大偏移）、`max_step`（最大单步跳变）与 `cum_jitter`（最大累计修订路程）。
4. **视觉 v2 在线入口与 3D 对应去重（P0-4 / P1-17）**：`node.py` 按配置开启 `read_keyframe(..., load_visual=...)`，`MapStore` 支持可选视觉观测保存/重载；`visual.py` 在最终 Kabsch 重拟合后按 1 mm 量化 3D 对应去重并复核内点门限。
5. **ICP 精确 MAP 权重与质心平移不变性（`a27f186` / P2-1）**：去除 `registration.py` 重力先验权重误乘 `len(points)` 的 bug，采用精确 $w_g=(\sigma_p/\sigma_g)^2=6.25$；线性化移至目标质心并按尺度归一化判秩。
6. **其余关键修复**：`backend.py` 修复 `exclude_recent=0` 切片、候选里程门预过滤、B2/B3 统一 `_up_body` 与 ZUPT 终位残差重算；`correction.py` 拦截倒退时间戳并对 `confirmations>2` 要求两两互一致；`surface-gate` 解耦 ZUPT 体素 `max(map_voxel_m, 0.2)`（D3 `zupt_pivot` 由 `160` 回归基线 `20`）；`measured-submaps` 预设改为 `anchor_mode="candidate"`；全部分支预设同步 `graph_gravity_sigma_rad=null` 并导出专属统计与 `loop_events.json`（JSON 禁用 `NaN`）。

## 4. D3 现象与根因复盘

1. **已修复的早期退化根因**：初版 `9ec9837` 在 `D3` 上退化至 `0.258 m`，原因有二：① `registration.py` 误将 ICP 重力权重乘以 `len(points)`（放大 ~500×，压制实测楼板平面约束，`a27f186` 已修）；② 全图节点开启一元 `graph_gravity_sigma_rad=0.02` 将上层位姿锁在前端俯仰偏置上（默认预设已改为 `null`）。
2. **D3 前端漂移形态（按真值位姿核对）**：前端在爬楼进入二楼区域（数组索引 `540`，源序号 `541`）时 Z 误差升至 `+0.6273 m`，在二楼巡航段（索引 `640..780`，相对高度 `3.298–3.327 m`）持续偏高，下楼途中（索引 `840`，相对起点 `[-7.258, 9.029, +1.824] m`、距起点 `11.73 m`）Z 误差自然回落至 `+0.0166 m`，末帧（索引 `875`，相对起点 `[0.278, -0.022, +0.002] m`）回到原点时 Z 误差仅 `-0.0020 m`。这种“上层高漂、返航回落”的拱形误差无法仅靠一楼原点回环拉平，依赖楼梯口与二楼段的高精度回环约束。
3. **单帧稳定化与三路 v2 的实证分歧**：
   - `B0_default`（`330` 边、`0.1442 m`）凭借 9× 更硬的 Roll/Pitch 回环权与弱 Cauchy（`10.0`）强拉 Z，但代价是 `cum_jitter=4.186 m`、`max_step=0.522 m`，且在 D1（`Tilt 8.48°`）与 D2（`0.1858 m`）全面崩坏。
   - `B0_aniso`（`330` 边、`0.1624 m`）→ `stabilized_nospacing`（`294` 边、`0.1771 m`）→ `stabilized`（`166` 边、`0.1882 m`）反映的是单帧 32 线 LiDAR 在保守信息矩阵与回环节流下的精度/稳定性折中；其中 `0.5 m` 间距减少 `128` 条边，终图上升 `1.11 cm` 而耗时降 `24%`。
   - **突破 `< 0.13 m` 的两条已验证路径**：① `v2_visual_akaze_only` 用全量视觉几何验真剔除低置信 SC 边，仅用 `77` 条高质量边在 **84.1 s** 内取得 **`0.0825 m`（Z `0.0561 m`、Online `0.1022 m`）**，而未对 SC 边验真的融合模式（`v2_visual_akaze`，`0.2161 m`）反而受劣质 SC 边拖累；② `v2_ms` 用实测多帧子图 + `candidate` 锚点在低噪声 IMU 的 D3 上将终图压至 **`0.1268 m`**（`nospacing` **`0.1126 m`**），但在高噪声 IMU 的 D2 上因长帧间跨度出现运动涂抹（`0.1741 m`）。

## 5. 选型建议与待验证边界

- **无相机/弱纹理或高噪声 IMU 通用离线底座**：推荐 `exp/slam-backend-stabilization`（`slam_backend_stabilized.json`），在 D1（`0.0997 m`）与 D2（`0.0554 m`）取得最优终图，零 `L2` 负跳变，且可按需叠加柔和表面门（`v2_sg_soft`，D2 `0.0608 m`、倾角 `0.28°`）。
- **有已标定同步 RGB 且以同向重访为主的多层场景**：推荐 `exp/slam-v2-visual-retrieval` 的**全量视觉验真模式**（`slam_v2_visual_akaze_only.json`），D1 `0.0997 m`、D3 `0.0825 m` / `84.1 s`；但在反向重访居多的探索场景（如 D2）中，单目前视 FOV 仅召回 `11–23` 条边（`0.1837 / 0.1348 m`），不适合替代 360° LiDAR 全场景默认。
- **未在本机验证项（留待 Isaac Sim / ROS 2 实跑验收）**：① 主启动器冻结下发指定 JSON 并核验收据；② 回环优化单步峰值（D3 基线曾达 ~2 s）期间导航端实际接收修正的时延；③ 在线 ROS spool 携带 `visual.npz` 入库与先验地图重载的端到端实跑。
